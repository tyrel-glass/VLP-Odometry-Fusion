# Known-pose LSTM--EKF comparison

The saved LSTM, position-only EKF, and one-step-heading EKF use the same known Vive pose at raw sample 19 and the same 300 evaluation samples from dataset 10. The LSTM weights are unchanged. EKF process and measurement covariances use datasets 1--8 only; dataset 9 is not used to select an EKF design. Dataset 10 was excluded from fitting but inspected during exploratory EKF formulation development. Accordingly, this is a descriptive comparison, not an unbiased test of EKF design selection. The one-step heading is a sensitivity case derived from the same VLP positions, with their full empirical position--heading covariance. These are offline estimates and no closed-loop EKF trial was recorded.
